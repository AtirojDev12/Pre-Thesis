# ไฟอาคารและสวิตช์

## ห้องน้ำชายและหญิงใน Cinema_GamePlay

สวิตช์ `Light Switch (toilet light)` ใต้ `Men's Toilet` และ `Women's Toilet`
ใช้ E เปิด/ปิดเฉพาะห้องของตัวเอง โดยเชื่อม `ToiletLight > Building Zone Id`
กับโซน `MaleToilet` และ `FemaleToilet` ตามลำดับ ทั้งไฟหลัก ไฟบรรยากาศ
ข้อความสวิตช์ และกฎที่ตรวจความมืดใช้สถานะห้องเดียวกัน มีเสียงคลิกเมื่อกดสวิตช์
และสถานะแยกห้องส่งให้ผู้เล่นที่เข้ามาภายหลังด้วย

ใน `Building Lights > Zone Lighting` แต่ละโซนอ้างถึง `Toilet/ToiletLight/MLight`
และ `Toilet/ToiletLight/WMLight` ตามลำดับ ไฟหลักที่ผู้สร้างซีนปิด GameObject
ไว้ยังคงปิดอยู่ สามารถเปิดใช้งานชุดนั้นใน Inspector ได้หากต้องการเพิ่มแสงหลัก
ไฟบรรยากาศยังคงค่าความสว่างและการกะพริบเดิม ปิดไฟอาคารแล้วไฟทั้งสองห้องดับ
แต่เก็บตำแหน่งสวิตช์รายห้องไว้เพื่อคืนสถานะเมื่อไฟอาคารกลับมา

สวิตช์ `SLMaleToilet` และ `SLFemaleToilet` ของชุดห้องน้ำใน Hallway ใช้โซน
`HallwayMaleToilet` / `HallwayFemaleToilet` แยกต่างหาก จึงไม่ควบคุมไฟในสองห้องนี้
โดยโซน Hallway ใช้เฉพาะกลุ่มไฟ ไม่กำหนดกล่องตรวจตำแหน่งเพิ่มเติม

ทดสอบการแยกห้องและสถานะผู้เล่นเข้าใหม่ด้วย
`Tests/AudioNetwork/ToiletZoneChecks.cs` ผ่านเมธอด `ToiletZoneChecks.Run`
ในโปรเจกต์ทดสอบ Unity แยก

`BuildingLightManager` เป็นเจ้าของสถานะไฟ ส่งสถานะผ่าน Mirror และทำงานได้แม้ไม่มี `GhostManager` ในฉาก สวิตช์ E, ปุ่ม L และคำสั่งจากระบบเกมใช้ตัวควบคุมเดียวกัน ผีอ่านสถานะเพื่อเลือกวิธีไล่ล่า แต่ไม่กะพริบไฟหรือเปิดไฟกลับเมื่อจบรอบแล้ว

## เพิ่มหลอดไฟ

- ในฉาก Cinema, Cinema_GamePlay, Z1_EnemyTest และ NewEnemyplus มีวัตถุ `Building Lights` เตรียมไว้แล้ว
- เพิ่มหรือทำสำเนาวัตถุที่มี `Light` ในฉากนั้นได้เลย ไม่ต้องลากเข้ารายการของผี หลอดที่เพิ่มระหว่างเล่นจะถูกตรวจพบภายในประมาณ 0.5 วินาที หรือทันทีเมื่อสลับไฟ
- ไฟที่ตั้งปิดไว้ตั้งแต่แรกจะยังปิดอยู่เมื่อเปิดไฟอาคาร
- ไฟฉายและไฟใต้กล้อง/ผู้เล่นถูกเว้นให้อัตโนมัติ สำหรับไฟฉุกเฉินหรือไฟเอฟเฟกต์ที่ต้องทำงานเอง ให้เพิ่ม `IndependentLight` ที่วัตถุไฟหรือวัตถุแม่
- ฉากใหม่: ใช้ `Tools > Pre-Thesis > Lighting > Add Building Lights To Scene` แล้วบันทึกฉาก หรือใช้เมนูตั้งค่าสวิตช์ซึ่งเพิ่มตัวควบคุมให้ด้วย ต้องมีตัวควบคุมเพียงหนึ่งตัวต่อฉากเกมที่ใช้งาน

แสงที่อบลง lightmap และแสงจากวัสดุเรืองแสงไม่ได้หายไปจากการปิด `Light.enabled` หากต้องการให้หลอดดับจริง ควรใช้ Realtime lighting สำหรับหลอดที่สวิตช์ควบคุม และตรวจวัสดุเรืองแสงของโมเดลด้วย
